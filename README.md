# Hotel Aalayaa - Full Stack App

## Setup

1. Copy `.env.example` to `.env` and fill values
2. Install dependencies: `npm install`
3. Run: `npm start`

## Env vars
- WA_TOKEN, WA_PHONE_ID, VERIFY_TOKEN, APP_SECRET
- STAFF_PARUTHIPPATTU, STAFF_JAKCITY
- APP_URL
- DB_TYPE (sqlite or pg), DATABASE_URL, SQLITE_PATH
- RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET, RAZORPAY_WEBHOOK_SECRET
- TOKEN_SECRET, SESSION_SECRET
- ADMIN_EMAIL, ADMIN_PASSWORD
- CORS_ORIGIN

## Deploy on Render
- Build Command: `npm install`
- Start Command: `npm start`
- Add managed Postgres, set DATABASE_URL
- Set all env vars
